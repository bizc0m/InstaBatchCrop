# Guide utilisateur

## Traitement rapide

1. Ouvrir l'application.
2. Glisser des images dans la zone de depot.
3. Selectionner les formats voulus: portrait, carre, story.
4. Choisir le type d'export: JPEG, PNG ou WebP.
5. Regler la compression si l'export est en JPEG.
6. Cliquer `Traiter toutes les photos`.

## Corriger le cadrage

- Selectionner une image dans la file.
- Utiliser l'aperçu avant / apres.
- Dans l'aperçu apres, deplacer directement le cadrage a la souris.
- Utiliser les fleches et le zoom pour affiner.
- Les corrections sont conservees pour le traitement batch pendant la session.

## Marquer une priorite

- Mode `Point`: cliquer sur un sujet important.
- Mode `Zone`: dessiner une zone importante.
- Ces priorites aident le moteur a garder cette partie dans le cadre.

## Watermark

Le watermark est optionnel.

Reglages disponibles:

- activation;
- texte;
- couleur;
- logo/image transparente;
- position;
- opacite;
- taille;
- marge.

Le watermark est applique sur chaque export final.

## File d'images

- Selectionner une ou plusieurs images pour les retirer de la file.
- `Vider` nettoie toute la file.
- Les fichiers sources sur le disque ne sont jamais supprimes.
